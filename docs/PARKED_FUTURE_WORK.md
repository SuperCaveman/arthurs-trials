# Parked future work

## Current portfolio scope

Arthur's Trials is currently a **game-development multiplayer platform**. Its
public architecture, case study, capture plan, and default-off AWS roadmap are
all centered on dedicated-server hosting, session placement, match results,
operations, and cost-aware scaling for multiplayer games.

## Preserved, not claimed

The repository also preserves early virtual-production research and local proof
scripts. That work is intentionally paused. It is not presented as an active
customer solution, a completed cloud deployment, or part of the current video
demo. No additional virtual-production AWS resources should be created unless a
future scope decision explicitly resumes it.

Keeping it in version control avoids losing useful exploration while keeping
the portfolio story focused and evidence-based.
